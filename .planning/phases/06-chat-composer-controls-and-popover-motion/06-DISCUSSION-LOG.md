## 控件行的窄屏适配

### 屏幕较窄时的布局

| Option | Description | Selected |
|--------|-------------|----------|
| 单行固定，优先截断模型名 | 权限和思考程度保持完整，模型吸收剩余宽度。 | ✓ |
| 自动切换为紧凑标签 | 空间不足时缩短文案或只保留图标。 | |
| 允许横向滚动 | 保留完整标签，通过横向滑动查看。 | |

**User's choice:** 单行固定，优先截断模型名。
**Notes:** 不换行、不使用横向滚动。

### 模型名称截断位置

| Option | Description | Selected |
|--------|-------------|----------|
| 保留开头 | 显示模型家族，省略名称尾部。 | |
| 保留结尾 | 沿用当前紧凑布局的头部省略方式。 | |
| 同时保留首尾 | 使用中间截断，兼顾模型家族与变体。 | ✓ |

**User's choice:** 同时保留首尾。
**Notes:** 模型控件采用中间截断。

### 控件文案密度

| Option | Description | Selected |
|--------|-------------|----------|
| 只显示当前选中值 | 不增加字段名前缀或额外图标。 | ✓ |
| 图标加当前值 | 为权限、模型与思考程度增加图标。 | |
| 字段名加当前值 | 显示“权限：”“模型：”等前缀。 | |

**User's choice:** 只显示当前选中值。
**Notes:** 视觉语言与当前权限组件一致。

### 查看完整模型名

| Option | Description | Selected |
|--------|-------------|----------|
| 在模型窗口中查看 | 窗口显示完整名称，当前项带选中标记。 | ✓ |
| 桌面悬停提示 | 桌面悬停显示，移动端在窗口中查看。 | |
| 长按控件显示 | 通过长按显示完整名称。 | |

**User's choice:** 在模型窗口中查看。
**Notes:** 不增加悬停或长按专用行为。

## 弹窗内容与触发关系

### 窗口内容分组

| Option | Description | Selected |
|--------|-------------|----------|
| 三项各自独立 | 每个控件只打开自己的选项。 | |
| 三项共用组合窗口 | 任一控件都打开包含三项的窗口。 | |
| 权限独立，模型与思考程度合并 | 权限单独显示，相关的模型和思考程度共用窗口。 | ✓ |

**User's choice:** 权限独立，模型与思考程度合并。
**Notes:** 不沿用当前桌面三项全部合并的行为。

### 组合窗口初始内容

| Option | Description | Selected |
|--------|-------------|----------|
| 被点击的部分排在最前 | 根据触发控件动态调整两个部分的顺序。 | ✓ |
| 固定模型在上 | 固定顺序并自动定位到被点击部分。 | |
| 使用两个页签 | 点击控件时打开对应页签。 | |

**User's choice:** 被点击的部分排在最前。
**Notes:** 另一部分紧随其后，不使用页签。

### 选中后的关闭行为

| Option | Description | Selected |
|--------|-------------|----------|
| 按选项类型处理 | 权限和思考程度立即关闭，模型保持打开。 | ✓ |
| 任意选项立即关闭 | 每次选择后都关闭窗口。 | |
| 始终保持打开 | 仅点击外部时关闭。 | |

**User's choice:** 按选项类型处理。
**Notes:** 模型选择后保留窗口，以便检查或调整思考程度。

### 不兼容思考程度

| Option | Description | Selected |
|--------|-------------|----------|
| 自动回退并更新选中状态 | 回退到受支持的默认值，窗口保持打开。 | ✓ |
| 自动回退并关闭 | 自动切换后立即关闭窗口。 | |
| 强制手动选择 | 选择有效程度前不完成模型切换。 | |

**User's choice:** 自动回退并更新选中状态。
**Notes:** 沿用现有回退逻辑，并让变化在窗口中可见。

## 跨平台弹窗形态

### 平台实现策略

| Option | Description | Selected |
|--------|-------------|----------|
| 移动端原生菜单，Web 自定义弹窗 | 恢复旧版移动菜单生命周期，Web 使用锚定弹窗。 | ✓ |
| 全平台自定义弹窗 | 所有平台使用统一自定义实现。 | |
| 仅权限恢复旧菜单 | 模型与思考程度保留当前分支。 | |

**User's choice:** 移动端原生菜单，Web 自定义锚定弹窗。
**Notes:** 内容和交互一致，视觉允许遵循平台惯例。

### 明暗主题

| Option | Description | Selected |
|--------|-------------|----------|
| 跟随 Happy App 主题 | 弹窗与应用当前主题一致。 | ✓ |
| 移动端跟随系统 | 移动端使用系统主题，Web 使用应用主题。 | |
| 固定深色 | 所有平台始终使用深色。 | |

**User's choice:** 跟随 Happy App 主题。
**Notes:** 当前 iOS 菜单固定深色的行为需要修正。

### 窄屏 Web 形态

| Option | Description | Selected |
|--------|-------------|----------|
| 受视口约束的锚定弹窗 | 自动调整对齐、高度并允许滚动。 | ✓ |
| 底部弹层 | 在窄屏切换为底部面板。 | |
| 输入框上方整行面板 | 展开并占用聊天内容空间。 | |

**User's choice:** 受视口约束的锚定弹窗。
**Notes:** 不因 Web 变窄而切换交互形态。

### 锚点和展开方向

| Option | Description | Selected |
|--------|-------------|----------|
| 锚定被点击控件 | 优先向上，空间不足时翻转或调整对齐。 | ✓ |
| 锚定整个控件行 | 所有窗口从相同位置打开。 | |
| 居中显示 | 使用与控件无关的居中窗口。 | |

**User's choice:** 锚定被点击控件。
**Notes:** 始终保留视口安全间距。

## 键盘、背景与动画体验

### 键盘保持策略

| Option | Description | Selected |
|--------|-------------|----------|
| 保持键盘并立即打开 | 不触发输入区重排。 | ✓ |
| 收起键盘后打开 | 等布局稳定后再显示窗口。 | |
| 按平台处理 | 原生保持键盘，Web 收起键盘。 | |

**User's choice:** 保持键盘并立即打开。
**Notes:** 窗口使用键盘上方的可用空间。

### 页面背景处理

| Option | Description | Selected |
|--------|-------------|----------|
| 背景完全不变 | 使用透明点击关闭层，不调暗、不模糊。 | ✓ |
| 轻微调暗 | 遮罩随窗口淡入淡出。 | |
| 局部模糊 | 保留窗口周边玻璃效果。 | |

**User's choice:** 背景完全不变。
**Notes:** 去除导致背景重绘风险的局部模糊层。

### 开合动画

| Option | Description | Selected |
|--------|-------------|----------|
| 淡入并小幅上移和缩放 | Web 约 180ms 打开、140ms 关闭；移动端使用系统动画。 | ✓ |
| 仅淡入淡出 | 不使用位移或缩放。 | |
| 弹性展开 | 使用更明显的弹性动画。 | |

**User's choice:** 淡入并小幅上移和缩放。
**Notes:** 动效应轻微、稳定，不抢夺注意力。

### 已打开窗口的切换

| Option | Description | Selected |
|--------|-------------|----------|
| 直接切换 | 复用弹层并移动到新锚点。 | |
| 顺序关闭再打开 | 自动完成关闭和重新打开。 | |
| 必须先手动关闭 | 当前窗口关闭前不能打开另一个窗口。 | ✓ |

**User's choice:** 必须先手动关闭。
**Notes:** 不实现弹层内容和锚点的直接切换。
