# Phase 06 — UI Design Contract

> Visual and interaction contract for Phase 06. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

本合同只定义聊天输入区现有权限、模型和思考程度控件的布局、菜单呈现与生命周期。它不增加模型、权限、思考程度、会话能力、设置入口或协议行为。上游产品决定 D-01 至 D-16 全部为锁定约束。

---

## Design System

| Property | Value |
|----------|-------|
| Tool | React Native Unistyles `~3.1.1`（现有主题与尺寸令牌） |
| Preset | not applicable；本项目为 React Native/Expo App，未使用 shadcn |
| Component library | React Native `0.83.1` + Expo UI `~55.0.5`；复用现有 `NativeSettingsMenu`、`AnchoredActionMenu` 与 Reanimated |
| Icon library | `@expo/vector-icons` Ionicons；只用于现有权限语义图标与菜单选中标记，不新增装饰图标 |
| Font | IBM Plex Sans：`IBMPlexSans-Regular` / `IBMPlexSans-SemiBold` |

### Existing-system rule

- 控件与菜单必须消费 `useUnistyles()` 的当前主题，禁止复制颜色常量建立第二套主题。
- iOS 使用系统 `Menu` 的材质、圆角、阴影和平台动效；Android/Web 才使用仓库内锚定菜单表面。
- 不安装新组件库、弹窗库、动画库或 registry block。
- 不恢复已删除的 `SessionStatusBar`，也不恢复旧权限按钮的底部布局；只恢复旧入口验证过的菜单生命周期。

## Spacing Scale

沿用项目 `theme.ts` 的 4px 基准，不建立阶段私有的互斥 spacing system：

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | 窄屏控件间距、状态行底部间距、紧凑内联间距 |
| sm | 8px | 标准控件间距、视口安全边距、hit slop 基础值 |
| md | 12px | 320–359px 视口的状态行左右内边距、菜单项垂直内边距 |
| lg | 16px | ≥360px 状态行左右内边距与最右侧协调间距 |
| xl | 20px | 菜单项正文行高，不用于额外容器嵌套 |
| 2xl | 24px | 仅继承现有节间距；本阶段不新增大区块 |
| 3xl | 32px | 菜单分组标题最小高度、模型触发器内容收缩基准 |

Exceptions: 锚点与菜单表面的间隔固定为 6px，沿用 `resolveAnchoredMenuPlacement` 的现有几何；菜单边框使用 `StyleSheet.hairlineWidth`。触发器视觉高度为 28px，垂直 hit slop 为 8px，从而得到至少 44px 的有效触控高度；这属于触控尺寸而非 spacing token。

## Typography

本阶段只使用 3 个字号和 2 个字重；不引入 display type。

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Control value | 11px | Regular 400 | 16px |
| Group heading | 12px | Semibold 600 | 16px |
| Menu option / body | 14px | Regular 400 | 20px |
| Selected menu option | 14px | Semibold 600 | 20px |

- 所有文字使用 `Typography.default()` 或 `Typography.default('semiBold')`，不得使用系统默认字体替代。
- 三个触发器均为单行。权限与思考程度不得截断；模型名称使用中间省略，保留首尾。
- 模型菜单项必须显示完整名称：允许自然换行并增加行高，不得在菜单中使用头部、尾部或中间省略。
- 分组标题只出现在组合菜单内容中；触发器本身不得显示“权限”“模型”“思考程度”等字段名前缀。

## Color

比例描述的是本阶段表面层级，不改变全局主题分配。

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `theme.colors.surface`：Light `#FFFFFF`；Dark Web `#212121`；Dark native `#161616` | 页面与输入区既有背景；窗口打开期间保持逐像素不变 |
| Secondary (30%) | `theme.colors.input.background`：Light `#F5F5F5`；Dark Web `#303030`；Dark native `#1E1E1E` | Web/Android 菜单表面；iOS 改用当前系统主题材质 |
| Accent (10%) | `theme.colors.radio.active`：Light `#007AFF`；Dark `#0A84FF` | 仅用于当前选项 checkmark、Web 键盘焦点环和必要的选中指示 |
| Destructive | none | 本阶段没有破坏性操作，菜单不得引入红色确认动作 |

Accent reserved for: 当前选项标记、Web 可见焦点环；不得把所有触发器文字或整块菜单染成 accent。

补充主题规则：

- 权限触发器继续使用现有 `theme.colors.permission.*` 语义色；颜色只是辅助信息，完整权限值必须存在于可访问名称中。
- 普通菜单文字使用 `theme.colors.text`，次级/不可用文字使用 `theme.colors.textSecondary`，分隔线使用 `theme.colors.divider`。
- Android/Web 表面边框使用 `theme.colors.glass.border`；Web 阴影沿用 `shadowOpacity: 0.1`、`shadowOffset: {0, 3}`、`shadowRadius: 8`、`elevation: 6`。
- iOS `Host.colorScheme` 必须由当前 Happy 主题派生；禁止保留固定 `dark` 或固定白色 tint。
- 关闭层固定为透明。不得使用 scrim、dim、`LocalBlurHalo`、`BlurView` 或任何局部/全局模糊。

## Copywriting Contract

| Element | Copy |
|---------|------|
| Primary CTA | 不适用：本阶段无新增主 CTA；三个触发器的可见文案仅为当前选中值 |
| Empty state heading | 不适用：选项继续由现有会话能力提供，本阶段不新增菜单内空状态 |
| Empty state body | 不适用：若现有数据未提供有效当前值/回调，不渲染可点击的空触发器，也不发明占位文案 |
| Error state | 不适用：选择失败继续由现有 session mutation/error owner 处理；弹窗不得新增本地错误文案或吞掉既有错误 |
| Destructive confirmation | none；没有破坏性操作或确认步骤 |

### Visible and accessible labels

- 可见触发器：只显示已本地化的当前值；权限入口可保留当前语义 play/pause 图标，模型与思考程度不得新增图标、chevron 或字段前缀。
- 组合窗口分组标题：复用现有本地化“模型”和“思考程度”字段名；权限窗口不重复显示冗余标题。
- 可访问触发器名称必须包含字段名和完整当前值，例如“模型：{完整模型名}”；不得把截断后的屏幕文字作为 accessibility label。
- 透明关闭层复用现有 `common.cancel`/关闭菜单语义；不显示可见“取消”按钮。

## Composer Control Row

### Placement and order

1. 控件簇位于消息发送框正上方，始终保持一个水平行，顺序固定为：权限 → 模型 → 思考程度 → 右侧留白。（D-01）
2. 现有 connection/context 信息仍留在状态行的 leading 区域，不改变其语义；三个选择控件构成 trailing 控件簇。不得把任一控件放回底部 action row，也不得保留重复入口。
3. ≥360px 宽度时，状态行左右内边距 16px、控件间距 8px、最右留白 16px；320–359px 时分别为 12px、4px、12px。
4. 状态行总高度由 28px 触发器和 4px 底部间距组成；不得因打开菜单或键盘状态改变高度。
5. 支持的验收宽度从 320px 起；320、375、700、701 和 1024px 都必须保留相同顺序，不换行、不横向滚动、不重叠。

### Flex and truncation

| Control | Flex contract | Text contract |
|---------|---------------|---------------|
| Permission | `flexShrink: 0`，有效点击框最小 44×44px | 完整单行显示，不截断 |
| Model | 唯一允许收缩的控件；`minWidth: 44px`、`maxWidth: 176px`、内部文本 `minWidth: 0` | `numberOfLines={1}` + `ellipsizeMode="middle"`，保留名称首尾 |
| Effort | `flexShrink: 0`，有效点击框最小 44×44px | 完整单行显示，不截断 |

- 模型先吸收所有控件簇内的宽度压力。（D-02）当模型已达到 44px 且 leading 状态文本仍竞争空间时，leading 状态文本才可单行尾部省略；权限与思考程度仍不得截断。
- 模型完整名称必须在模型窗口和可访问名称中出现，当前模型必须有非纯颜色的选中标记。（D-03）
- 触发器没有 pill/card 背景；沿用权限控件的轻量文本视觉。按下态只把整个触发器 opacity 调到 `0.6`，不得引发尺寸变化。
- Web 键盘焦点显示 2px accent 焦点环和 2px offset；鼠标按下态与焦点态不得改变布局尺寸。

## Menu Content and Selection

| Trigger | Window | Content order | Selection result |
|---------|--------|---------------|------------------|
| Permission | 独立权限窗口 | 权限选项直接列出 | 选择后立即关闭 |
| Model | 模型/思考程度组合窗口 | 模型分组在前，思考程度分组紧随 | 选择模型后保持打开 |
| Effort | 同一个模型/思考程度组合窗口 | 思考程度分组在前，模型分组紧随 | 选择思考程度后立即关闭 |

- “同一个组合窗口”指共享同一份可见状态、锚定层和关闭生命周期；不得为模型与思考程度维护两套独立 popup。（D-05、D-06）
- 组合窗口内每个分组有 32px 最小高度的 12/16 semibold 标题；选项最小高度 44px、水平内边距 14px、垂直内边距 12px。
- 选项文字可换行并让行高自然增长。内容超过窗口上限时滚动菜单内容，标题随内容滚动；不得裁切完整模型名。
- 当前项使用 Ionicons `checkmark` 与 `accessibilityState.selected=true`；未选项不放置造成列宽跳动的可见占位图标，应为标记列预留稳定 18px 宽度。
- 选择模型后，窗口锚点、滚动位置和分组顺序保持不变。若现有兼容性逻辑自动回退思考程度，思考程度 checkmark 在同一个仍打开的窗口中更新，不显示 toast、不闪烁、不临时呈现旧选中态。（D-07、D-08）
- 选项 key 必须先在当前 option array 中解析；未知或陈旧 key 不得发送 mutation，也不得回退成 prompt text。

## Platform Presentation

### iOS native

- 复用 Expo UI SwiftUI `Host` + 系统 `Menu` 生命周期；一个触发动作只创建一个系统菜单。（D-09）
- 系统外观跟随 Happy 当前 light/dark 主题，不固定深色，不固定白色 tint。（D-10）
- 权限与思考程度 action 使用系统默认关闭行为；模型 action 在 iOS 16.4+ 使用 no-dismiss 行为。低版本行为受下方兼容性门约束。
- 定位、圆角、阴影、入退场和 Reduced Motion 由系统菜单负责；不得在系统菜单外再包一层自定义 dim/blur overlay。

### Android native

- 使用现有透明 modal + `measureInWindow` + `AnchoredActionMenu` 路径，不替换为居中 dialog 或 bottom sheet。（D-09、D-12）
- 关闭层覆盖窗口、背景完全透明并消费点击，避免 click-through；菜单表面使用主题色且 `glassEnabled=false`。
- 菜单按触发器测得的 window rect 锚定，并把 safe-area 与当前键盘高度传入共享 placement helper。
- 复用平台/系统 Reduced Motion 行为；不得为 native 菜单叠加 Web 180/140ms 动效。

### Web, including narrow Web

- 使用自定义锚定 popover，不在窄屏切换成居中 modal、bottom sheet 或整行面板。（D-11、D-12）
- 权限窗口期望宽度 224px；组合窗口期望宽度 320px。实际宽度为 `min(期望宽度, viewport - safe-area - 16px)`。
- 内容期望高度由真实内容测量，最大 400px；实际高度再受锚点所在方向可用空间限制，超出部分垂直滚动。
- 水平边界固定为 safe-area 加 8px viewport margin；菜单与触发器固定间隔 6px。
- 表面圆角 14px、hairline border、主题背景和现有菜单阴影；关闭层没有自己的 enter/exit 动画。

## Placement Algorithm

Android 与 Web 的三个菜单调用方使用 above-first 偏好；不得全局改变其他 `AnchoredActionMenu` 调用方的现有 below-first 默认值。

1. 获取被点击触发器的 window rect；宽或高 ≤0 时不打开，且不改变键盘/输入框状态。
2. 可用边界为：safe-area 各边 + 8px；底边额外减去可见键盘高度。
3. 完整内容候选顺序固定为 `above-end → above-start → below-end → below-start`。
4. 第一个完整容纳宽高的候选胜出；`end` 对齐优先，使表面靠近触发器右边缘。
5. 若没有方向可完整容纳高度，选择可用高度更大的一侧；相等时选上方。高度收缩到该侧可用值并启用内容滚动。
6. `left` 和 `top` 最终 clamp 到可用边界；菜单不得覆盖安全区、可见键盘或越出视口。
7. 锚点与菜单之间保留 6px，不与触发器重叠。窗口尺寸变化、旋转或键盘几何变化时重新计算，不产生一帧越界位置。

## Focus, Backdrop, and Dismissal

- 指针/触控打开任一控件时，不调用 `Keyboard.dismiss()`、`inputRef.blur()` 或 `KeyboardDismissCoordinator`；输入键盘保持打开，composer 高度和锚点不得重排。（D-13）
- Web 指针打开路径在 pointer-down 阶段阻止触发器抢走输入焦点；键盘激活路径允许把焦点从触发器移入菜单以完成可访问导航。
- Web 键盘导航：Tab 可到达三个触发器；Enter/Space 打开；Escape 关闭；方向键或 Tab 可遍历选项；关闭后，键盘打开路径把焦点还给原触发器，指针路径维持原 composer focus。
- Native 使用系统 back/escape 请求关闭；Web 点击透明关闭层或 Escape 关闭。权限/思考程度选择本身关闭，模型选择本身不关闭。
- 打开期间背景颜色、opacity、blur 和布局全部不变。透明关闭层只负责消费点击与关闭，不得 animate。（D-14）
- 同一时刻只允许一个窗口。窗口打开时，其他两个触发器位于透明关闭层之后；点击另一个触发器的第一次点击只能关闭当前窗口，不得在同一事件中打开新窗口。退出完成后，用户第二次点击才可打开目标窗口。（D-16）
- Web 退出 140ms 期间保留透明关闭层与最后一个有效 anchor，阻止 click-through；退出回调后立即卸载 portal，不得留下拦截页面的透明层。

## Motion Contract

### Web surface only

| Phase | Duration | Easing | Values |
|-------|----------|--------|--------|
| Enter | 180ms | `Easing.out(Easing.cubic)` | opacity `0→1`，scale `0.96→1`，translateY `8px→0` |
| Exit | 140ms | `Easing.in(Easing.cubic)` | opacity `1→0`；位置和尺寸保持稳定 |

- 只动画菜单表面，绝不动画页面背景、透明关闭层或整个 modal。（D-15）
- transform origin 指向锚点一侧：上方窗口使用 bottom-end，下方窗口使用 top-end；翻转方向后起点仍不得出现位置跳跃。
- 进入和退出都由 Reanimated builder/回调驱动，禁止 `setTimeout` 模拟动画生命周期。
- `ReduceMotion.System` 必须接入。系统要求减少动态效果时，取消 scale/translate 并立即完成 enter/exit；关闭层卸载与可点击状态仍保持正确。
- iOS/Android 原生菜单只使用系统动效与系统 Reduced Motion 设置，不复制 Web 时间曲线。

## Accessibility Contract

- 三个触发器均为 `accessibilityRole="button"`，公开完整字段名/当前值，并准确更新 `accessibilityState.expanded`。
- Web/Android 菜单表面使用 modal/menu 语义，打开时限制辅助技术浏览范围；关闭后恢复到正确触发器或输入框路径。
- 每个选项公开完整 label、selected、disabled 状态；checkmark 不能是唯一的辅助技术选中信号。
- 所有有效触控目标至少 44×44px；相邻 hitSlop 不得重叠到会触发错误控件。
- 模型中间省略只影响视觉渲染；screen reader、tooltip/完整菜单项始终读出完整名称。
- 颜色不作为权限或选中状态的唯一载体。权限值、选中语义和 checkmark 必须在 light/dark 主题下都可辨认。
- 动画期间 accessibility tree 不得重复出现两份菜单；退出中的表面不可再次操作，但关闭层继续阻止 click-through。

## iOS 15.1–16.3 Compatibility Gate

Expo SDK 55 支持 iOS 15.1+，但 `menuActionDismissBehavior` 仅在 iOS 16.4+ 生效。D-07（选模型后保持窗口打开）与 D-09（iOS 使用系统菜单）因此构成强制先决门：

1. 在完整重构前先实现最小 SwiftUI `Menu` + model `Picker`/action spike。
2. 至少在一个 iOS 15.1–16.3 runtime 和一个 iOS 16.4+ runtime 上验证：选择模型后系统菜单保持打开、模型 checkmark 更新、自动 effort fallback 的 checkmark 在同一菜单中实时更新、随后选择 effort 会关闭。
3. 记录 OS 版本、交互录像/截图或等价可复核证据；仅在当前最新版 iOS 通过不算完成。
4. 若 15.1–16.3 无法同时满足保持打开和 live update，Phase 06 必须停在该 checkpoint 并请求产品/支持范围决策。不得静默让低版本选择模型后关闭，不得私自把低版本改成自定义 popover，也不得宣称 D-07/D-09 已满足。
5. Checker/verification 在上述证据缺失时应把 iOS 兼容性标记为 human-needed/blocking，而不是把 TypeScript 测试通过当作替代证据。

## Responsive and Theme Acceptance Matrix

| Surface | Required contract evidence |
|---------|----------------------------|
| Web 320px | 12px row inset、4px gaps、模型中间省略；权限/effort 完整；320px 组合窗 clamp 到 304px；无水平 overflow |

## Interaction State Matrix

| State | Visual / behavior contract |
|-------|----------------------------|
| Closed | 三个控件单行；无 popup layer；composer focus/keyboard 按原状态工作 |
| Opening | 立即建立透明 click-away layer；Web 表面按 180ms 进入，native 由系统进入；背景不变 |
| Open permission | 只显示权限选项；当前项有 checkmark；其他触发器不能直接切换 |
| Open model-first | 模型分组在前；选模型保持打开并实时更新 model/effort selection |
| Open effort-first | effort 分组在前；选 effort 立即关闭；选 model 仍保持打开 |
| Closing | Web 表面 140ms fade；透明层继续拦截；native 使用系统关闭；结束后无残留层 |
| Reduced motion | Web 无 transform/定时动画并立即稳定到终态；背景和焦点规则不变 |
| Invalid/stale option | 不发送 mutation、不生成 prompt、不记录 payload；保留既有有效选择 |
