# Product

## Register

product

## Users

Software engineers who run Claude Code or Codex on a computer and need to monitor, guide, and approve agent work from a phone while away from their desk.

## Product Purpose

Happy provides a secure mobile and web control surface for coding-agent sessions. It should make switching devices, sending instructions, reviewing progress, and responding to permissions feel immediate without exposing unencrypted source data.

## Brand Personality

Quiet, direct, dependable. The interface should feel familiar to experienced tool users and keep attention on the active coding session.

## Anti-references

- Marketing-style decoration inside operational screens.
- Controls whose low contrast makes their affordance disappear.
- Heavy black-or-white action fills that dominate compact composer surfaces.
- Novel interaction patterns where a standard mobile control would be clearer.

## Design Principles

- Keep the coding session visually primary and let controls recede until needed.
- Use familiar mobile affordances with enough contrast to identify state and action.
- Reserve strong emphasis for urgent or consequential operations such as stopping a running agent.
- Keep equivalent controls consistent across session, home, and new-session composers.
- Preserve user intent across devices without allowing remote state to overwrite explicit local choices.

## Accessibility & Inclusion

Support light and dark system themes, standard touch targets, explicit accessibility labels, and state indicators that do not rely on color alone. Maintain readable icon and text contrast while distinguishing enabled, disabled, loading, and destructive states.
